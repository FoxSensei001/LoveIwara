## 🌟 แนะนำ

**Love Iwara** (หรือที่รู้จักในชื่อ `i_iwara` หรือ **2i**) คือไคลเอนต์บุคคลที่สามสำหรับ [Iwara](https://www.iwara.tv) ที่สร้างด้วย Flutter มีเป้าหมายเพื่อมอบประสบการณ์การใช้งานที่ลื่นไหลและรู้สึกเป็นธรรมชาติบนโทรศัพท์ แท็บเล็ต และเดสก์ท็อป — ทั้งหมดจากโค้ดเบสเดียวที่ครอบคลุม **Android, Meta Quest, Windows, macOS, Linux และ iOS**

> [!NOTE]
> โปรเจกต์นี้เริ่มต้นจากโปรเจกต์เพื่อการเรียนรู้ — ความพยายามครั้งแรกของฉันในการสร้างแอป Flutter ข้ามแพลตฟอร์ม โค้ดบางส่วนอาจไม่ได้ขัดเกลาอย่างสมบูรณ์แบบ แต่ก็ได้รับการดูแลรักษาอย่างต่อเนื่องและเต็มไปด้วยฟีเจอร์ต่าง ๆ หากคุณกำลังเรียนรู้ Flutter อยู่เช่นกัน ฉันหวังว่าเราจะเติบโตไปด้วยกันได้ ยินดีต้อนรับ PR และฟีดแบ็กเสมอ!

> [!IMPORTANT]
> **ข้อจำกัดในการใช้งาน** — โปรเจกต์นี้มีไว้สำหรับการเรียนรู้และใช้อ้างอิงส่วนตัวเท่านั้น และ **ไม่แนะนำให้ใช้งานจริงในระดับโปรดักชัน** **ห้ามโปรโมตโปรเจกต์นี้บนแพลตฟอร์มสาธารณะใด ๆ โดยเด็ดขาด** การละเมิดอาจส่งผลให้การดูแลรักษาหยุดลงและรีโพซิทอรีถูกลบ

> [!WARNING]
> **ข้อจำกัดความรับผิดชอบ** — ผู้พัฒนาไม่มีความเกี่ยวข้องใด ๆ กับ Iwara หรือผู้ให้บริการเนื้อหาของ Iwara แอปพลิเคชันนี้ไม่ได้โฮสต์เนื้อหาของตัวเองเลยแม้แต่น้อย

### 🎥 วิดีโอ
- การเล่นวิดีโอที่ลื่นไหลด้วย **media_kit** (libmpv)
- เลือกคุณภาพ · ควบคุมความเร็วในการเล่น (รวมถึงความเร็วเริ่มต้น/อัตโนมัติ) · เต็มหน้าจอ
- ภาพตัวอย่าง **การเลื่อนดูตำแหน่ง** เมื่อวางเมาส์หรือลากแถบความคืบหน้า
- **ไทม์สแตมป์ที่คลิกได้** — กระโดดไปยังช่วงเวลาที่ต้องการทันทีจากไทม์สแตมป์ที่ไฮไลต์ไว้ในคำบรรยายและความคิดเห็น
- ลิ้นชัก **"ดูต่อ"** + เล่นอัตโนมัติเมื่อเข้าสู่วิดีโอ (เลือกได้)
- ตัวแสดงความเร็วในการโหลดแบบเรียลไทม์
- **ตัวแสดงภาพพาโนรามาบนหน้าจอแบน** — ไฟล์ VR180 / 360° ปกติจะแสดงเป็นสองครึ่งที่ถูกบีบให้แบน แต่ที่นี่คุณจะได้วิวพอร์ตที่มีสัดส่วนถูกต้องซึ่งสามารถลากเพื่อมองไปรอบ ๆ ได้ ไฟล์ของ Iwara ไม่มีเมทาดาทาทรงกลมเลย ดังนั้นรูปแบบจะถูกเดาโดยฮิวริสติก — แก้ไขด้วยมือได้ และระบบจะจดจำการแก้ไขนั้นไว้สำหรับวิดีโอนั้น
- **"ระยะการมอง"** — กดค้างเพื่อดันภาพออกไปไกลขึ้นหรือดึงเข้ามาใกล้ขึ้น (ซูมภาพสำหรับวิดีโอแบน มุมมองภาพสำหรับวิดีโอพาโนรามา)
- **เปิดด้วยแอปอื่น** — ส่งต่อวิดีโอปัจจุบันไปยัง MX Player / VLC ไปยังเครื่องเล่น VR เช่น Skybox หรือ Pigasus หรือไปยังเครื่องเล่นภายนอกที่กำหนดเองบนเดสก์ท็อป โดยจะให้ความสำคัญกับไฟล์ในเครื่องหรือไฟล์ที่ดาวน์โหลดไว้แล้วก่อน และ "คัดลอกลิงก์" เป็นทางเลือกสำรอง
- เดสก์ท็อป: **ลากแล้ววาง** ไฟล์วิดีโอในเครื่องลงบนหน้าต่างเพื่อเล่นทันที

### 🥽 Meta Quest / VR
*ให้บริการเป็น APK `quest` แยกต่างหากที่สร้างบน Meta Spatial SDK บิลด์ Android ปกติไม่ได้เชื่อมโยงกับส่วนนี้เลย และ `minSdk` ของมันก็ยังคงเดิม*

**แอปนี้อาศัยอยู่ในสภาพแวดล้อมเชิงพื้นที่** เมื่อเปิดจากหน้าโฮมของ Quest คุณจะเข้าสู่พื้นที่แบบดื่มด่ำที่ประจำอยู่ทันที ทั้งแอป — การเรียกดู การค้นหา ความคิดเห็น คีย์บอร์ดบนหน้าจอ — ลอยอยู่ตรงหน้าคุณในรูปแบบพาเนล 2D โดยไม่มีส่วนไหนถูกตัดทอน พาเนลนี้ **โค้งเล็กน้อย** (ส่วนโค้ง 30° — ประมาณจอที่มีความโค้ง "3000R" ที่ความกว้างเริ่มต้น 1.6 ม.) สิ่งที่คงที่คือส่วนโค้ง ไม่ใช่รัศมี ดังนั้นความโค้งจะดูเหมือนเดิมไม่ว่าคุณจะลากหน้าต่างให้กว้างหรือแคบแค่ไหน

**สามหน้าต่าง ท่าทางชุดเดียว** พาเนลแอป หน้าจอ และพาเนลควบคุมต่างก็มีกรอบของตัวเอง: ปุ่มจับ (grip trigger) ใช้ลากหน้าต่างที่ตัวมัน ขอบใช้ลาก มุมใช้ปรับขนาดรอบจุดศูนย์กลาง และหน้าต่างจะหันเข้าหาคุณเสมอ ขนาดและตำแหน่งจะถูกจดจำไว้ จะไม่มีอะไรปรากฏขึ้นจนกว่าการติดตามศีรษะจะนิ่ง — ไม่มีหน้าต่างกะพริบขึ้นในตำแหน่งที่ผิดแล้วกระโดดไปมา

**เครื่องเล่นกลายเป็นหน้าจอในพื้นที่** เปิดวิดีโอแล้วมันจะสลับให้โดยอัตโนมัติ (เลือกได้)
- **รูปทรงหน้าจอ** — แบน หรือความโค้งสามระดับ ระยะห่าง ความกว้าง และสัดส่วนภาพปรับได้ และจะถูกจดจำไว้ *แยกตามแต่ละสัดส่วนภาพ* ดังนั้นเมื่อกลับไปดูคลิป 4:3 เลย์เอาต์ที่คุณตั้งไว้สำหรับ 4:3 จะถูกเรียกคืนมา
- **รูปแบบวิดีโอ** — 2D / 3D, side-by-side ครึ่ง/เต็ม, over-under ครึ่ง/เต็ม, equirectangular 180° และ 360° ตรวจจับอัตโนมัติจากไฟล์และแก้ไขด้วยมือได้ EAC และ fisheye จะถูกจดจำได้ แต่ระบุว่าไม่รองรับ และเสนอให้ใช้เครื่องเล่นภายนอกแทน
- **การเล่น** — ความเร็ว 0.5×–3.0× วนซ้ำ ระดับเสียง ตัวอย่างการเลื่อนที่แสดงเวลาเป้าหมายและส่วนต่าง ตัวแสดงสถานะบัฟเฟอร์บนหน้าจอเอง รวมถึงนาฬิกาและแบตเตอรี่บนพาเนล
- **"ดูต่อ" ภายในพื้นที่** — กลุ่มวิดีโอแบบแบ่งหมวดหมู่เดียวกับแอป 2D (รายการแหล่งที่มา การติดตาม เพลย์ลิสต์ รายการโปรด การดาวน์โหลด ดูภายหลัง) พร้อมภาพปก สลับวิดีโอได้โดยไม่ต้องออกจากพื้นที่ พาเนลจะแสดงสถานะกำลังโหลด และนำวิดีโอเก่ากลับมาหากวิดีโอถัดไปโหลดไม่สำเร็จ
- **จัดการลิงก์ที่กำลังจะหมดอายุ** — แหล่งที่มาจะถูกรีเฟรชก่อนหมดอายุ และหากเกิด 404 ระหว่างเล่น ระบบจะรีเฟรชและเล่นต่อจากจุดเดิม
- **ฉาก (Scenes)** — พาสทรู หรือความว่างเปล่า

**แกลเลอรีเชิงพื้นที่** แกลเลอรีจะเปิดเป็นเวทีขนาดใหญ่หนึ่งเวทีพร้อมแถบฟิล์ม ดังนั้นชุดภาพหลายสิบภาพ — รวมถึงวิดีโอที่ปะปนอยู่ในนั้น — จะยังคงเป็นวัตถุชิ้นเดียว ไม่ใช่เลเยอร์หลายสิบชั้น สไลด์โชว์ที่ 3 / 5 / 10 / 20 วินาที คุณภาพมาตรฐานหรือต้นฉบับ และลากไปด้านข้างบนเวทีเพื่อพลิกดู ภาพแนวตั้งจะถูกจัดให้พอดีกับกรอบ 16:9 เพื่อไม่ให้ภาพประกอบสัดส่วน 9:16 สูงเกะกะจนบังสายตา

**มือหรือคอนโทรลเลอร์**
- *มือ* — เรย์และการหยิบจับแบบทางการ การหยิบจับที่ใดก็ได้นอกพาเนลจะสลับเปิด/ปิดพาเนลควบคุม
- *คอนโทรลเลอร์* — A/X เล่น/หยุดชั่วคราว, B/Y ปิดพาเนลหรือกลับสู่แอป, Menu เปิดการตั้งค่า ปุ่มจับ (grip trigger) สามารถคว้าหน้าจอได้โดยไม่ต้องเล็ง แท่งควบคุม (stick) ใช้เลื่อนซ้าย/ขวาแบบมีความเร่ง (กดครั้งเดียวคือ 5 วินาที ค้างไว้จะเร่งขึ้นถึง 15 นาทีต่อวินาที) และดันหน้าจอให้ใกล้หรือไกลขึ้นในแนวขึ้น/ลง
- การถอดเฮดเซ็ตออกจะหยุดการเล่นชั่วคราว และการใส่กลับเข้าไปจะเล่นต่อ การรีเซ็นเตอร์ของระบบจะจัดวางทุกอย่างกลับมาตรงหน้าคุณอีกครั้ง

**การเปิดใช้งานครั้งแรกจะเริ่มด้วยบทเรียน** คำแนะนำการใช้งานครั้งแรกสำหรับเฮดเซ็ตไม่ใช่แบบหน้าจอสัมผัสที่ยกมาใช้ ("หยิบเพื่อซูม กดค้างเพื่อปรับความเร็ว") — เพราะไม่มีภาพที่สัมผัสได้ในพื้นที่นั้น แต่จะมีสองคอร์สแทน คือ **วิดีโอเชิงพื้นที่** และ **แกลเลอรีเชิงพื้นที่**: ภาพประกอบคอนโทรลเลอร์จะเคลื่อนไหวทีละเฟรมไปพร้อมกับปุ่มและแท่งควบคุมของมัน หน้าจอ พาเนล และเรย์จะอยู่ในตำแหน่งเรขาคณิตจริง และทุกการเคลื่อนไหวจะแสดงให้เห็นทั้งสำหรับคอนโทรลเลอร์และมือเปล่า เมื่อเปิดใช้ "ลดการเคลื่อนไหว" ของระบบ จะวาดเป็นภาพนิ่งข้อมูลเดียวแทน สามารถเล่นซ้ำได้ทุกเมื่อจากหน้าการตั้งค่า

<summary><b>🔐 การตั้งค่าการเซ็นชื่อ Android</b></summary>

หากต้องการสร้าง APK รุ่นเผยแพร่ที่มีลายเซ็น:

**1. สร้าง keystore** (รันภายใน `android/app`):
```bash
keytool -genkeypair -v -keystore keystore.jks -alias <your_key_alias> -keyalg RSA -keysize 2048 -validity 10000
```
ตรวจสอบให้แน่ใจว่า `keystore.jks` อยู่ใน `android/app`

**2. ตั้งค่าการเซ็นชื่อ** ใน `android/app/build.gradle`:
```groovy
signingConfigs {
    release {
        storeFile file("keystore.jks")
        storePassword System.getenv("KEYSTORE_PASSWORD") ?: project.findProperty("MY_KEYSTORE_PASSWORD")
        keyAlias System.getenv("KEY_ALIAS") ?: project.findProperty("MY_KEY_ALIAS")
        keyPassword System.getenv("KEY_PASSWORD") ?: project.findProperty("MY_KEY_PASSWORD")
    }
}
```
และเพิ่มค่าตัวยึดตำแหน่งใน `android/gradle.properties`:
```properties
MY_KEYSTORE_PASSWORD=${KEYSTORE_PASSWORD}
MY_KEY_ALIAS=${KEY_ALIAS}
MY_KEY_PASSWORD=${KEY_PASSWORD}
```

**3. GitHub Actions** — เพิ่ม Secrets ของรีโพซิทอรี: `KEYSTORE_BASE64` (base64 ของ `keystore.jks`), `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD` จากนั้นใน `.github/workflows/build.yml`:
```yaml
env:
  KEYSTORE_PASSWORD: ${{ secrets.KEYSTORE_PASSWORD }}
  KEY_ALIAS: ${{ secrets.KEY_ALIAS }}
  KEY_PASSWORD: ${{ secrets.KEY_PASSWORD }}

steps:
  - name: Setup Keystore
    run: |
      echo "${{ secrets.KEYSTORE_BASE64 }}" | base64 --decode > android/app/keystore.jks
    shell: bash
```

**4. สร้างบิลด์** — `flutter build apk --release --flavor standard` → ผลลัพธ์อยู่ที่ `build/app/outputs/flutter-apk/app-standard-release.apk` สำหรับบิลด์ Quest ให้ใช้ `flutter build apk --release --flavor quest --target-platform android-arm64` → `app-arm64-v8a-quest-release.apk`

### 🏷️ การแปลแท็กของ Iwara เป็นภาษาท้องถิ่น

แท็กดิบของ Iwara เป็นคีย์ในรูปแบบคล้ายภาษาอังกฤษ (เช่น `mother`, `blue_archive`) แอปนี้มาพร้อมพจนานุกรมที่ดูแลโดยชุมชนซึ่งจับคู่แต่ละแท็กกับ **ภาษาจีนตัวย่อ / ภาษาจีนตัวเต็ม / ภาษาญี่ปุ่น / ภาษาอังกฤษ** ดังนั้นแท็กจะแสดงผลในภาษาปัจจุบันของคุณทั่วทั้งหน้ารายละเอียด การค้นหา และหน้ารายการแท็ก

วิธีการทำงาน:

- **พจนานุกรม**: อยู่ใน [`tool/data/iwara_tags/`](tool/data/iwara_tags/) แอปใช้ไฟล์ [`iwara_tags.min.json`](tool/data/iwara_tags/iwara_tags.min.json) ที่รวมและบีบอัดแล้ว
- **การจัดส่ง**: บรรจุมาพร้อมแอปเป็นสำรองแบบออฟไลน์ (`assets/data/iwara_tags.min.json`) และอัปเดตแบบร้อนผ่าน jsDelivr CDN — ดังนั้นถ้อยคำสามารถปรับปรุงได้ **โดยไม่ต้องออกบิลด์แอปใหม่**
- **ภายในแอป**: ชิปแท็กจะแสดงชื่อที่แปลแล้ว บนการ์ดแท็กในหน้ารายละเอียด แถวขยาย/ยุบมีปุ่มไอคอนสำหรับสลับระหว่าง **คีย์ต้นฉบับ ⇄ คำแปล** การกดค้าง/คลิกขวาที่แท็ก (หรือแตะชื่อแท็กในหน้ารายการแท็ก) จะเปิดไดอะล็อกที่แสดงทั้งคำแปลและคีย์ต้นฉบับ ปุ่มคัดลอก และลิงก์สำหรับส่งฟีดแบ็ก

นี่คือการแปลแบบพยายามอย่างดีที่สุดของคำศัพท์กว่า 2,600 คำในหมวด ACG / Vtuber / NSFW และอาจมีข้อผิดพลาดได้

2. สร้างไฟล์ผลลัพธ์ที่รวมแล้วและอาเซ็ทที่บรรจุมากับแอปใหม่: `dart run tool/data/iwara_tags/build_localized_min.dart`
3. คอมมิตทั้งไฟล์ต้นฉบับและ `iwara_tags.min.json` ที่สร้างขึ้น (ดู [`tool/data/iwara_tags/README.md`](tool/data/iwara_tags/README.md))

เมทาดาทาของบุคคลที่สาม **Oreno3d** (ต้นฉบับ / ตัวละคร / แท็ก) ถูกแปลเป็นภาษาท้องถิ่นด้วยวิธีเดียวกัน — พจนานุกรมอยู่ใน [`tool/data/oreno3d_tags/`](tool/data/oreno3d_tags/) เป็นอาเซ็ทที่บรรจุมากับแอป + jsDelivr CDN แสดงในภาษาปัจจุบันของคุณบนหน้ารายละเอียดวิดีโอและการ์ดผลการค้นหา

> [!NOTE]
> พจนานุกรมแท็กทั้งสองข้างต้นดูแลรักษาเฉพาะ **zh-CN / zh-TW / ja / en เท่านั้น** — *ไม่ได้* ขยายไปยัง UI อีก 8 ภาษาที่เหลือ (ko / th / id / vi / es / ru / fr / de) คำศัพท์เหล่านี้กว่า 2,600 คำในหมวด ACG / Vtuber / ศัพท์เฉพาะโดจิน พึ่งพาสำนวนเฉพาะของกลุ่มซับคัลเจอร์มากกว่าการแปลตามตัวอักษร การขยายการแปลด้วย AI ไปยัง 12 ภาษาโดยไม่มีใครสามารถตรวจสอบผลลัพธ์ได้ มีความเสี่ยงที่จะเกิดแท็กที่แปลผิดโดยไม่มีใครรู้ ในภาษา UI ที่นอกเหนือจากสี่ภาษานี้ แท็กจะแสดงเป็นคีย์ดั้งเดิมของ Iwara/Oreno3d แทนที่จะเป็นคำแปล รายละเอียดและเหตุผลดูได้ที่ [`docs/i18n/README.md`](docs/i18n/README.md)
